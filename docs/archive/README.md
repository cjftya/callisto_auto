# 과거 계획·검증 기록

이 디렉터리는 작성 당시의 기록을 보존하는 아카이브임. **현재 실행·설치·모델 정책의 근거로 사용하지 않음.** 본문의 오래된 모델 고정, Work 실행 규칙, master 통합 절차, 공급자 미구현 상태는 현재 지침이 아님.

현재 기준: [아키텍처](../architecture.md), [지원 범위](../cli-capability-matrix.md), [전환 현황](../migration-status.md), 루트 `AGENTS.md`, 정식 스킬 원본임.

| 기록 | 보존 이유 |
| --- | --- |
| [v3 계획](plan-v3.0.md) | CLI 전환 초기 범위·원본 보존 의도 |
